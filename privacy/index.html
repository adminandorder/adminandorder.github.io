AdminAndOrder Pinner: privacy notice

AdminAndOrder is an Etsy shop of UK money and admin templates, run by Joe Lavery, a UK sole trader. AdminAndOrder Pinner is a private tool that publishes pins to AdminAndOrder's own Pinterest account, only ones Joe has approved one by one. It is not offered to anyone else.

What it uses

AdminAndOrder's own Pinterest account, through Pinterest's official API, with the permissions Joe granted: reading its own boards and pins, and creating pins.

What it keeps

For each pin it publishes, the pin's id, its board and the time, so the same pin is never published twice. It keeps no other information from Pinterest, collects nothing about any other Pinterest user, and sells or shares nothing.

Where

On a private server run by Joe, kept only while the tool is in use.
